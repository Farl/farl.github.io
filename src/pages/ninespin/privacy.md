# 九宮轉 隱私權政策

生效日期：2026-10-26

本政策說明 Farl Lee（以下稱「我」）開發的益智遊戲「九宮轉」（Ninespin，iOS、Android 與網頁版 ninespin.pages.dev）如何處理你的資料。

## 我不收集的資料

九宮轉沒有帳號系統，不會要求或收集你的姓名、電子郵件、電話或其他可直接識別你身分的資料。

## 本機存檔

關卡進度與設定只存在你的裝置上（App 內儲存空間或瀏覽器的本機儲存），不會上傳到我的伺服器。刪除 App 或清除瀏覽器資料就會一併刪除。

## 使用分析（PostHog、Firebase / Google Analytics）

為了改善遊戲，App 會傳送遊戲事件：遊玩的關卡、步數、花費時間、遊玩次數、購買事件與語言。

**什麼時候會傳送。** 在歐洲經濟區（EEA）、英國與瑞士，只有在你於啟動時的同意表單中，同意「在裝置上儲存或存取資訊」與「衡量內容成效」後才會開始分析；其他不需要同意的地區則預設開啟。取得同意之前不會傳送任何資料：事件只暫存在記憶體中，裝置上也不會儲存任何分析相關資料。若啟動時無法連上同意服務，該次啟動的事件會直接丟棄。

**傳送的內容。**

- [PostHog](https://posthog.com/privacy) 會收到上述遊戲事件，以及 App 產生的隨機安裝 ID、平台、App 版本與語言。不會建立個人檔案。PostHog 會由 IP 推得大致國家。
- [Firebase / Google Analytics](https://policies.google.com/technologies/partner-sites) 會收到相同的事件，以及 Firebase 自動收集的資料：App 執行個體 ID、首次開啟、工作階段、裝置型號與作業系統。Google 的廣告儲存、廣告使用者資料與個人化廣告同意設定會依照你的選擇。

**廣告 ID。** 分析資料不會與你的廣告 ID 連結。Android 版已關閉 Firebase 的廣告 ID 收集，iOS 版沒有讓 Firebase 取得 IDFA。PostHog 只使用它自己的隨機 ID。

**網頁版。** ninespin.pages.dev 只使用 PostHog，沒有 Google Analytics，也不為分析使用 Cookie 或本機儲存；隨機 ID 只存在記憶體中，僅限本次造訪。

## 廣告（Google AdMob）

iOS 與 Android 版會透過 Google AdMob 在關卡之間顯示廣告。Google 及其合作夥伴可能會使用：

- 裝置的廣告 ID（Android 廣告 ID；iOS 上的 IDFA 只有在你於「App 追蹤透明度」提示中同意後才會取得）
- 裝置資訊（例如機型、作業系統、語言、大致位置如 IP 推得的國家）
- 廣告互動與使用資料

用來顯示、衡量廣告並防止詐欺。若你位於歐洲經濟區、英國或瑞士，App 啟動時會透過 Google 的使用者訊息平台（UMP）詢問你的同意。詳見 [Google 如何使用合作夥伴網站或應用程式的資料](https://policies.google.com/technologies/partner-sites)。

你也可以在裝置設定中重設廣告 ID 或限制廣告追蹤。

## 變更或撤回同意

在需要同意的地區，App 標題畫面會顯示「**隱私選項**」連結，點開會進入 Google 的隱私選項表單，你可以隨時變更或撤回同意。拒絕或撤回同意後，暫存的分析事件會被丟棄、不再傳送任何資料、Firebase 收集會關閉，裝置上的安裝 ID 與尚未送出的分析資料也會刪除。

## App 內購買

購買（例如移除廣告）由 Apple（App Store）或 Google（Google Play）處理，我不會取得你的付款資料。

## 兒童

九宮轉不是針對 13 歲以下兒童設計，我也不會在知情的情況下收集兒童的個人資料。
